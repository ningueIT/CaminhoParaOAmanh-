# O Caminho para o Amanhecer

Plataforma 2D de aventura, puzzle e acao desenvolvido em Java puro com Swing.

## Controles

| Acao | Teclas |
| --- | --- |
| Mover | `A` / `D` ou setas esquerda / direita |
| Pular / pulo duplo | `Espaco` (pressione novamente no ar) |
| Esquivar | `Shift` |
| Ataque de garras direcional | Clique esquerdo (`M1`) mirando acima, abaixo, esquerda ou direita |
| Ataque de garras alternativo | `F` ou `J` |
| Magia / Luz da Aurora | `Q` |
| Usar pocao de vida | `1` |
| Usar pocao de mana | `2` |
| Interagir / confirmar runas | `E` |
| Menu | `Enter` |

Durante o minigame do Caminho dos Olhos, repita a sequencia com `W` / `A` / `S` / `D` ou as setas.

## Jornada

As cinco fases apresentam, respectivamente, o enigma das imagens, combate inicial, furtividade com sequencia de memoria, sentinelas aladas que exigem salto sobre a cabeca e a Entidade da Floresta. A magia tambem acende farois da Aurora, iluminando permanentemente a area, e queima vinhas corrompidas que bloqueiam caminhos. Colete fragmentos luminosos, poções de vida e poções de mana espalhadas pelo mapa; itens coletados acompanham a jornada. O chefe alterna investida, projeteis em leque e zonas de corrupcao telegrafadas, acelerando e encadeando investidas na segunda metade da vida. Sua derrota inicia a sequencia do colapso, a chegada do Cavaleiro e o amanhecer. A carta final fica disponivel para revisao no menu principal.
